# 🌐 Spring Boot JPA CRUD

A Spring Boot web application demonstrating **JPA-based CRUD operations** with **MySQL**.

---

## ✨ Features

* ➕ Add Product
* 📋 View Products
* 🔍 Get Product by ID
* ✏️ Update Product
* ❌ Delete Product
* 🔌 MySQL Database Connectivity
* 🌐 REST Controller
* 🗄️ JPA-based Repository
* ⚙️ Service Layer

## ▶️ How to Run

1. Clone or download the repository.
2. Open the project in Eclipse or Spring Tool Suite.
3. Create a MySQL database named `sb_web_jpa_crud`.
4. Configure your own MySQL username and password in `application.properties`.
5. Run `SbWebJpaCrudApplication.java`.
6. Test the CRUD APIs using Postman or any REST API client.
